# Soniox Transcriber for Obsidian

Realtime transcriptie vanuit Obsidian via Soniox.

## Features

- Live transcriptie
- Transcripties in aparte map
- Frontmatter-koppeling
- Speaker diarization-ready
- Configurabele transcriptiemap

## Installatie

1. Clone repo naar:
   `.obsidian/plugins/soniox-transcriber`

2. Run:
   ```bash
   npm install
   npm run build
   ```

3. Enable plugin in Obsidian.

## Configuratie

Voeg je Soniox API key toe in plugin settings.
